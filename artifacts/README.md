# Generated artifacts

The model is NOT included because the referenced source datasets were not uploaded.
After running `python -m src.train`, this folder will contain:

- `scholarship_model.joblib`: fitted Gradient Boosting model, preprocessing and frozen reference lookups
- `metrics.json`: held-out performance for Gradient Boosting
- `model_comparison.json` / `.csv`: metrics for Logistic Regression, Random Forest and Gradient Boosting (plus XGBoost if enabled)

These are generated by a local training run. Do not substitute the notebook's `awards` file directly: that file stores an estimator and transformer separately with a different interface.
